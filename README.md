# Hayrunnisa Portfolio OS

Next.js 16, TypeScript ve Tailwind CSS v4 ile hazırlanmış kişisel portföy.

## Kurulum

```bash
npm config set registry https://registry.npmjs.org/
npm install
npm run dev
```

Tarayıcı: `http://localhost:3000`

## İçerik düzenleme

Ana içerik ve bağlantılar: `components/portfolio-os.tsx`

CV bağlantısı henüz `#` olarak bırakıldı. CV dosyanı `public/hayrunnisa-erdem-cv.pdf` yoluna koyup bağlantıyı `/hayrunnisa-erdem-cv.pdf` yapabilirsin.
